# LLL Algorithm

A Python implementation of the Lenstra–Lenstra–Lovász (LLL) lattice reduction algorithm from scratch using NumPy.

## Features

- Gram–Schmidt orthogonalization.
- Size reduction.
- Lovász condition with δ = 0.75.
- Lattice basis reduction.

## Requirements

- Python 3
- NumPy
- Jupyter Notebook

## Usage

Open the "LLL.ipynb" notebook and run the cells to reduce the example lattice basis.

## Purpose

This educational project aims to understand lattice reduction algorithms and their mathematical foundations in the context of cryptography and cryptanalysis.
